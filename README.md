# Assistente Inteligente

Um assistente interativo desenvolvido com Python, Streamlit e OpenAI, que interpreta comandos em linguagem natural e os converte em consultas SQL para análise de dados. Ideal para usuários que desejam explorar bases de dados relacionais sem necessidade de conhecimento técnico em SQL.

## 🔍 Funcionalidades

- **Interpretação de Linguagem Natural:** Comandos em português são processados e convertidos em consultas SQL.
- **Execução de Consultas:** As consultas geradas são executadas em tempo real em uma base de dados relacional.
- **Interface Intuitiva:** Desenvolvida com Streamlit, proporcionando uma experiência de usuário amigável e responsiva.
- **Integração com OpenAI:** Utiliza modelos de linguagem para compreensão e geração de consultas precisas.
